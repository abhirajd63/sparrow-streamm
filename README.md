# Sparrow Stream - Video Streaming Web Application

Sparrow Stream is a **Node.js-based video streaming web application** designed to deliver media content efficiently. The application integrates the **Google Drive API** to fetch and stream videos while providing a responsive and user-friendly viewing experience.

## Live Demo

🔗 **https://abhirajd63.github.io/sparrow-streamm/**

## Features

- Stream video content using Google Drive API
- Efficient backend handling for smooth video playback
- Responsive and user-friendly interface
- Fast and seamless media delivery
- Organized video streaming experience

## Installation

### Prerequisites

- Node.js
- npm

### Steps

1. Clone the repository

```bash
git clone https://github.com/abhirajd63/sparrow-streamm.git
```

2. Navigate to the project directory

```bash
cd sparrow-streamm
```

3. Install dependencies

```bash
npm install
```

4. Configure the Google Drive API credentials if required.

5. Start the application

```bash
npm start
```

6. Open your browser and visit

```
http://localhost:3000
```

*(or the port configured in your application)*
